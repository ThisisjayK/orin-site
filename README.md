# Orin site (draft preview)

A draft preview of the Orin website: car cleaning and protection in Hyderabad.

All text is placeholder (lorem ipsum and square-bracket notes). This is not the final site and nothing here is a real offer, policy or price. The forms are not connected.

The pages are generated from a separate private project; this repository holds only the built files.
